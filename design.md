|---|---|---|
| `color-primary` | `#6366F1` | Main actions and links |
| `color-secondary` | `#8B5CF6` | Supporting actions |
| `color-background` | `#FFFFFF` | Page background |
| `color-surface` | `#F8FAFC` | Cards and panels |
| `color-text` | `#0F172A` | Primary text |
| `color-muted` | `#64748B` | Secondary text |
