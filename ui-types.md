## How to recommend a type
For each recommendation, include:
- Name and category
- Description
- Best-fit use cases
- Visual traits
- Relevant components
- Responsive considerations
- Accessibility considerations
- Trade-offs

Do not recommend a visual style solely because it is trendy. Consider the project's users, content, brand, and current implementation.
